Artwork used by the roster cards in index.html.

  zeus.jpg / poseidon.jpg / hades.jpg   -> in use
  artemis.jpg / ares.jpg / apollo.jpg   -> not yet wired up

Source PNGs were 1024x1536 / ~2 MB each. These are resized to
760px wide and saved as quality-82 JPEG (~110 KB), which is still
2.6x the on-screen size, so they stay sharp on high-DPI screens.
Re-export from the originals if you ever need larger.

The .svg files are fallback drawings. If a .jpg ever fails to
load, the card shows one of these instead of a broken image.
